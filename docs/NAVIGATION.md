# 操作与观察导航

本页说明当前应用的操作约定。它不是浏览器或触屏实测通过报告；覆盖与限制见 [验证说明](VERIFICATION.md)。

## 启动与整机观察

按 [首页](../README.md) 启动本地服务，打开终端提供的地址。自由观察时，左键拖动旋转，滚轮朝光标位置缩放，右键拖动平移。触屏控制约定为单指旋转、双指捏合缩放及双指拖动平移；实际设备效果仍须单独验收。

正视、侧视、俯视和部件检查锁定观察方向，可以先把翼根或桨毂平移至中央再放大。使用“恢复默认视角”重新取景；切换检查视角、进入或离开部件检查按对应预设取景。

透视相机与目标的距离范围为 0.2–240，正交倍率为 0.08–40。倍率相对于当前视野，不是光学放大率。相机没有实体碰撞，过度靠近可能穿过表面；检查窄缝和销轴更适合使用正交视角配合平移。

## 机构和飞行演示

- “展开”“收拢”与进度滑块控制同一整翼转换进度，可暂停、反向和逐位置观察
- 机翼与所属动力舱共同转动，黑色定长杆随翼端接头摆动，共用滑架沿机身移动
- 完整飞行演示提供概念起降与过渡轨迹，时长、速度和 RPM 不代表实机性能
- 线框、部件细节、关节与结构拆解用于观察不同层次；拆解视图不代表正常装配运动
- 页面提供播放/暂停控制，空格用于播放/暂停，Escape 用于退出当前检查；Python 与面板状态下按当前界面提示操作

## 内部驱动

1. 在“细节 / 线框 / 结构拆解”工具区点击“内部驱动”
2. 指定后机身壳体、槽内表面、减速箱罩及其表面附件暂时移开，显示电机、减速级、丝杠、滑架、横梁与连杆
3. 使用展开/收拢、进度和速度控制观察行程；取景覆盖机构完整行程，不随每帧滑架位置自动推拉
4. 再点击“内部驱动”、面板关闭、“恢复外壳与普通视图”或 Escape，恢复进入前的外壳可见状态

切换部件检查、结构拆解、其他预设、完整飞行或全局复位也会退出内部驱动检查。本视图按清单移开壳体，不是任意平面剖切；不会永久删除部件或改变源材料。

Python 实时控制和 JSON 回放期间仍可切换内部驱动。它只改变本地观察状态，不提交新的动作命令，不改变 Python 时钟、RPM、相位或回执。面板打开时第一次 Escape 只关闭该检查，不断开 Python。外部拆解状态下该入口暂不可用。

## Python 与离线记录

本机实时联动：启动 Python 同源服务，打开它给出的本机地址，点击“连接本机 Python 桥”，再运行 SDK 示例。外部控制期间本地动作工具禁用，仿真只由 Python 的明确时间步推进。

静态网页可导入 JSON，或点击“播放 Python 示例（离线）”。离线记录先整体校验，再进入回放；可播放、暂停和按进度定位。错误文件不应替换已有画面。支持的记录大小、命令格式和退出行为见 [Python 接口](PYTHON_API.md)。

观察桨叶旋向时可使用“0.1×慢放检视”。它放慢整条回放，显示 RPM 仍为仿真值。高速扫掠是基于实际叶片轨迹的显示近似，不是新增实体桨叶或独立的慢转桨毂。停止、暂停、收桨、寻位或断连后不应残留旧曝光。

## 退出与恢复

关闭外控、面板、复位或浏览器返回应释放相应事件订阅与控制状态。连接清理失败时，界面只能确认本地已退出，不能声称后端会话已经释放；服务可能等待租约到期。此类提示不应被离线导入隐藏。

如果模型未出现，先确认使用 HTTP 本地服务、依赖已安装、当前 `dist/` 与模型资源匹配。不要通过开放跨源访问、修改网络安全设置或远程静态站探测本机端口解决同源限制。
