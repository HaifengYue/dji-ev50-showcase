# 机腹直槽与低置直连驱动

当前模型使用整翼斜轴转换。活动外翼、动力舱与推进器共同绕主轴收展，主铰轴总旋转量为120°。这不是桨轴水平至竖直的方向夹角。几何及机构均为原创概念重建，不是原厂CAD、加工图或适航设计；下述数值均为模型单位。

本轮修正已写入冻结模型：机腹输出长槽的真实长边拉直，内部驱动下移，两侧末端输出改为单根直斜件。主翼曲面接缝、主轴、红色目标球、原球心、定长杆、翼运动轨迹及球铰自由度保持。正式完整验收状态以[验证说明](VERIFICATION.md)和绑定同一资产哈希的报告为准。

## 明确修改范围

保守关联集合为72个网格，其余211个网格严格保护。实际源几何改变40个网格、局部TRS改变22个节点；没有新增或删除场景节点，所有父级和原动画轨道保持。

- 62个`Drive_`网格及两侧`BraceBodyCarriage`：低置传动、贴底支承、低鞍座和单根直斜输出

两条前接缝保留各8条开边、两个边界环，不将装饰线封成承力壳；尾环保持单闭合分量。皮距上限保持原0.009/0.0065。运行编码中的五条装饰因量化包围盒变化产生重基变换，须按真实解码世界几何核对，不能误称机械节点下移。

## 四动力及验收边界

四台电机分别维护RPM、相位、折角和启停阶段。启动先展叶再升速；停止先减速、正向寻位再收叶。默认和安全复位为全部停机、相位归零、八叶收拢；GLB静态导出姿态不替代网页运行初始状态。
