## 修改

- 删除四根旧支柱、四个脚垫及附属接头，改为两只前部主轮加一只中心尾轮。
- 主起落架使用扁平复材弹性梁外形，加入金属轮轴、轮毂、橡胶胎和独立轮轴节点。尾轮使用简洁弹性支架和双侧轮叉。
- 重建连续机壳网格并细分，重新贴合舱盖线与锁扣；四个电机舱采用连续收尖曲面，移除突出的装饰散热环，减弱碳纤维法线纹理。
- 保留机翼、尾翼、运动部件名称、8 个升力和 3 个巡航旋翼轴心。
- 网页优先使用 GLB 内的轮组，不再重复添加运行时轮子；旧资产仍保留兼容分支。

Three.js 坐标为 X 横向、Y 向上、Z 向前，单位米：

| 节点            | 轮心                 | 外半径 |
| --------------- | -------------------- | ------ |
| Gear_Main_Left  | (-0.69, 0.105, 1.00) | 0.105  |
| Gear_Main_Right | (0.69, 0.105, 1.00)  | 0.105  |
| Gear_Tail       | (0, 0.065, -0.84)    | 0.065  |

轮组节点包含 `part=landing_wheel`、`radius_m`、`axle=local_X` 元数据。这里是外观模型，未求解重心、受力和地面动力学。

## 复现与检查

在仓库根目录执行 `blender -b --python blender/refine_airframe.py`，从 v09 重新生成 v12 源文件、GLB、六视图、透视图和起落架特写。脚本会写入 v12；修改参数前应将输出版本改为新版本以保留已有结果。预览使用无投影棚灯，减少 EEVEE 自阴影条带；不代表户外阴影表现。

确认后将生成的 GLB 复制到 `threejs/public/ev50.glb`。在 threejs 目录执行：

```text
npm run build
node test-airframe.mjs
npm run test:model
npm run test:api
npm run test:flight
```

本轮结果：构建通过；实际 GLB 三只轮胎接地、前后位置、旧支柱移除、11 个旋翼存在、运行时无重复轮组测试通过。API、仿真协议、HTTP、MAVLink 回归通过；三条航线共 32,403 个采样通过，保守净空 49 m。浏览器显示“模型就绪 · v12”，产品展示已查看，未捕获控制台 error。

glTF 校验 0 错误、38 警告、79 条信息；法线贴图切线由运行时生成，跨渲染器差异仍有可能。Vite 保留 Three.js 分块超过 500 kB 的体积提示。测试不等于全机所有零件的连续碰撞检测。旧离线视频没有重制，本轮未发布 GitHub Pages。
