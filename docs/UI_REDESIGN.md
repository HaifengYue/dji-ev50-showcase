# 交互界面重构说明

本次只调整网页信息架构、响应式布局与本地控制接线。主模型、Blender 源、压缩资源、机构求解、Python 协议与物理测试输入未修改。网页不展示工程发行版本号；模型内部格式和 API 协议标识仍保留。

## 可见结构

1. 页头提供机构演示、仿真接口和飞行器属性入口
2. 主视景独占主要宽度；画布不再叠加营销大标题、永久参数卡或重复控制条
3. 多角度预设、线框、内部驱动、拆解、自动环绕与视角复位集中到画布下方
4. 桌面检查说明使用独立右列；手机置于画布之后，画布高度不为说明压缩
5. “一个机体，两种可能”与独立机构控制合并；三种形态直接设置机构进度
6. 连续飞行序列嵌入仿真工作台，与 Python、JSON 回放和四电机共用同一个 SimulationRuntime
7. 厂商公开参数移入飞行器属性弹窗；关闭按钮、Escape、遮罩均可关闭，背景禁止交互，焦点循环并返回入口

## 控制来源与中断

- 工作区标签只控制面板显隐；不会自动播放、暂停或断开 Python
- 仿真工作台明确区分本地连续演示与手动四电机；进入手动会暂停飞行并清除原驱动电机命令，后续各电机独立更新
- 播放、阶段跳转和时间定位都经本地控制入口进入 demo 驱动，避免继承手动电机组合
- 本地控制入口先核对 runtime 当前控制权；外部控制或 JSON 回放不接受本地覆盖
- 明确本地动作取消尚在等待的 JSON 导入与 Python 接入意图，迟到结果不会夺取控制权
- 收起工作台、切换工作区或关闭属性/说明弹窗不会释放 Python；只有明确“退出外控 / 复位”或页面生命周期退出会触发释放
- 连接状态使用独立状态播报；不断变化的仿真秒数不放进 live region

## 响应式约束与验证边界

源码设定桌面画布为 clamp(400px, 59vh, 760px)，大屏适度增高；手机为 clamp(350px, 54svh, 570px)，最窄布局保持 340px 高。手机主操作保留约 44px 高点击区域，控制区按列换行，模态窗口限高并独立滚动。

自动检查覆盖 TypeScript、格式、Node 状态与竞态测试、React 静态标记、CSS/AST 结构约束、真实 GLB 加载与飞行回归。源码尺寸估算和静态标记检查不等于浏览器渲染验收。

本轮没有可交付的真实浏览器截图，也未验收桌面/手机点击、实际焦点循环、触屏及 GPU 表现。已知云端浏览器本地预览入口报告 ERR_BLOCKED_BY_CLIENT；没有以替换主机、其他浏览器协议或禁用安全限制绕过该限制。需在受支持的本地浏览器预览路线可用时补验 320×568、390×844、768×1024 与 1440×900：水平溢出、画布可达性、模态打开关闭与焦点返回、外控中关闭弹窗、切换标签及反复收起面板。
