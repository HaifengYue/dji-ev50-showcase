# 验证范围

运行 `npm test`、`npm run test:qa`、Python单测与前端构建，验证当前界面/API/运行模型。运行 `npm run build:model` 从唯一native独立重烘焙后，检查：

1. 原生源SHA与独立预期契约一致，烘焙前后网格有向面/材料身份不变
2. 全部285网格所有者与352节点、父子关系、材质绑定及动画保持
3. 全部关键Float32位置与序列化局部变换保持，运行模型不超批准预算
4. 两组烘焙动画、实际生产运动控制器及全owner拓扑检查
5. 材质primitive合并规则的正反例单测

`npm run test:pipeline`另核五个传动转轴的源/运行静态TRS及所有旋转轨逐值一致。

每次构造的实际状态和命令退出码见未提交的`build/model/REBUILD_RECEIPT.json`，不能用上次收据替代新模型验收。源码契约、重建成功与离散运动采样不构成连续碰撞、气密、强度或适航证明。历史界面契约中的旧证明只作追溯，不自动继承为新几何材料验收。

Git只保留当前源码、必要测试/契约和一份原生源。完整历史程序化冷重建以及大证据在历史归档中，新管线的模式明确为当前native重烘焙/导出。

当前native的完整物理复验入口为`npm run verify:model`：661全机倾转采样、252折桨/旋翼状态、150逐舵面角度、14,592独立舵面组合和1,201内部传动姿态，以及闭合owner内非邻接三角对的有限自交/共面面积检查。完整物理扫描要求先运行build:model取得同源的角色感知拓扑门。`python3 tools/verify_model.py --quick`仅是舵面烟测，不能代替完整验收。大输出写入`build/verification/`，不进入源码。

压缩器对8个折桨铰臂及腹部小传感器追加源Float32保护，消除旧运行体因量化引入的9个开口，不改作者网格。现政策要求源与运行体均为265闭合owner、20个明确列出的开放涂装/装配线owner；具体结果仍以当前源SHA绑定的实际报告为准。

当前运行体预算仍为4,300,000字节，实际4,296,228字节。本轮不降低位置/法线精度、不删模型部件、不改变碰撞/面积/距离门。仅移除网页scene extras中两项完整诊断JSON的重复副本：`transverseOutputRefinementJSON`与`centerWingSmoothing20261008`，共减少14,300字节；原生模型及外部manifest保留完整报告。压缩器核对报告内容与独立契约等价，并验证除此两键之外的scene extras全部逐值保持，所有对象extras仍保留。

当前已接受源的精简检查摘要与准确SHA见`qa/acceptance-summary.json`；其引用的逐项详细报告在单独验证证据归档，不作为当前源码依赖。

## 自由观察与呈现采样

默认自由透视观察；首次载入和显式复位按完整机构行程包络取景。机构播放、暂停、反向、拖动、机构复位、内部可视层/拆解切换不隐式更改视角或重新取景。显式视角预设、部件特写及飞行取景仍可改变镜头。调整窗口只更新投影宽高比。

`src/cameraPersistence.test.ts`实际挂载React/R3F中的生产CameraRig，使用真实Three透视/正交相机和OrbitControls，逐帧核对位置、方向、up、target、zoom及controls实例，覆盖重复输入和被中断的显式镜头动画。渲染器在该测试中为stub，因此这项测试不等同于真实浏览器像素或鼠标事件验收。本地浏览器受执行环境连接限制，发布站点的浏览器检查单独报告。

高质量模式使用1.5–2倍像素采样和最高4096阴影贴图；窄画布即使手动选择高质量仍将阴影限制到2048，并尊重设备纹理上限。低质量保持1倍采样并关闭阴影，窄屏和减少动态偏好默认进入低质量。切换质量或阴影尺寸会释放旧GPU目标。`renderQuality.test.ts`与`sceneShadows.test.ts`检查这些策略及运动中的阴影覆盖；采样改善不替代模型的实体几何修复。
