# 工程说明

本工程把当前 Transwing 概念模型的编辑、运行和验证资源放在同一处。它只呈现一个蓝白 P4 参考构型；独立动力模块是同一飞机的部件说明，校准合同与测试夹具也不是额外机型。

机腹输出槽直边、内部驱动总成下移及单根直斜输出已落盘冻结，功能化目录迁移已完成。作者链、前端五阶段、离线视觉及独立物理44阶段均已通过，精确范围与未运行项目见 [验证说明](VERIFICATION.md)。

## 可做的事情

- 浏览整机、切换观察方向、缩放和平移，检查机翼、接头、舵面和货舱
- 连续展开与收拢整翼，暂停、反向或拖动进度；动力舱随所属机翼运动
- 检查固定执行器、减速级、丝杠、共用滑架、横梁与定长连杆
- 展示四台电机各自的展桨、升速、运转、减速、寻位和收桨
- 播放概念飞行轨迹；通过本机 Python SDK 输入位置、姿态与动作，或导入 JSON 离线回放
- 编辑 Blender 源，重建网页 GLB，并使用同工程中的必要资源复验

## 核心目录

- `src/`：React、Three.js 场景、交互、运动状态机和源码测试
- `public/`：网页模型、模型清单、公开离线示例等静态资源
- `assets/blender/`：当前可编辑源与未压缩导出
- `scripts/`：生成、压缩、原始值重建比对及辅助检查
- `python/`：标准库本机桥、SDK、协议结构和 Python 测试
- `examples/python/`：离线记录生成和实时驱动示例
- `qa/current/`：当前独立检查与最终结果
- `qa/lib/`：当前真正导入的通用验证算法
- `qa/contracts/`：现用阈值、接口与校准合同
- `qa/reference/`：必要节点指纹、参考补片、原始证据和来源说明
- `qa/frontend/`：源码、飞行/加载、格式、构建、Python 五阶段检查
- `qa/visual/`：当前三张检查图、五秒动作视频及来源/接触可读性证据
- `qa/` 根目录：飞行与加载回归入口
- `docs/`：当前工程的中文说明
- `dist/`：由当前源码构建的网页，不应作为第二套源码编辑

最终文件集合由包内 `PROJECT_MANIFEST.json` 记录；清单逐项绑定实际字节数、SHA-256、CRC32及权限。

## 环境与依赖

前端需要 Node.js 22.12+，使用工程 `package-lock.json` 安装。模型生成记录使用 Blender 4.3.2 与 Node.js 24；更换工具版本需要重新验证几何、法线、动画及压缩输出。Python 需要 3.10+，运行和 SDK 无第三方 Python 包；`.venv` 由本机安装器重建。

启动与构建命令见 [首页](../README.md)。构建保留 `--emptyOutDir false`，不自动删除已有 `dist/` 文件。依赖本地安装目录和虚拟环境不随工程分发，第三方软件许可保留在 `THIRD_PARTY_NOTICES.txt`，具体版本以锁文件为准。

## 模型真实性

公开资料支持整翼斜轴转换、四个翼载推进器、细长机身及 V 尾等外观和机构类型。内部尺寸、材料、轴承支承、齿形、驱动比、桨叶细节和行程约束属于原创概念重建。公开图像用作观察参考，不作为本工程随包模型、纹理或影像分发。

模型展示的旋向和折桨时序不代表原厂飞控。应用不求解真实推力、重力、气动、载荷、碰撞反力或失效策略，也不连接真实无人机、串口、ROS 或 MAVLink。
