# SkyCaptain 视觉验收

本文说明当前仓库如何验证画面与行为，不是当前提交的成功报告。每次验收须关联准确 SHA、实际运行终态和看过的截图；旧提交、测试源码或 HTTP 200 都不能代替新像素证据。历史失败与调整保留在 [历史视觉记录](history/VISUAL-VALIDATION-20261009.md)。

## 验证层次

1. `npm run ci`：格式、构建、契约、实际 GLB 几何、机械、飞行、景观和 Python 等非浏览器检查。
2. Chromium 机库套件：真实 WebGL 页面、机构、相机、生命周期、演示与控制回执。
3. Chromium 景观套件：山区/海岛切换、外控保持、URL/本地偏好与页面恢复。
4. Chromium 色调截图：参考/当前固定视角、两机型两场景、金色光线与移动端，并验证返回产品曝光。
5. 部署后公开 smoke：逐文件 SHA-256 一致性和实际 Pages 子路径三维渲染。
6. 人工像素审查：模型、景观、天空、航迹、转子和可读性；行为断言通过不等于所有角度的画面都正确。

运行/安装命令见 [开发规范](../CONTRIBUTING.md#分层验证)。完整 Blender rebake、有限物理采样、视频编码、硬件 FPS 与外部训练分别需要自己的验证，不包含在上述结论中。

## 重点像素检查

- 产品舞台：两机型完整、可辨，EV50 与 SkyTrans 没有重复地板/灯光/画布。
- 自由观察：在自己的构图下改变机构、独立电机或舵面，画面不被重新框选；明确的检查视角仍正常。
- 蓝天、山区与海岛：山区绿色层次、村镇/道路/河湖可辨，海岛浅海/沙岸/树群清楚；亮部不过分泛白，模型、HUD 和航迹不互相淹没。
- 飞行：SkyTrans 上升/下降速度、316 秒阶段、后桨停转折叠及恢复、落地完整停车；EV50 保留原任务。
- 转子：1× 巡航前桨扫掠、0.1× 实体叶片、暂停与完全停车无残留曝光层；检查 front/side 等近轴视角，不能只看 wide。
- 航迹：连续飞行累积的近端、扩散与较老尾端，暂停冻结，恢复后消散；跳时、换源、切机与场景切换不得连接旧色带。
- 小屏与输出：面板收起后模型可见、可拖动，截图输出是真实画面；实际视频编码需另验。

现有山地连续飞行用例在约 173.5 秒与 181–182 秒分别截图。第二张通过正常 UI 4× 分段推进并回到 1× 累积至少 8 秒历史，不能再次 seek 或注入轨迹来冒充连续消散。历史较老尾端可能在镜头外；不能仅从 `historySeconds` 推断完整尾端已经可见。

## 预算与判定

[浏览器工作流](../.github/workflows/integration-browser.yml)将机库、景观和色调截图分成三个 job，整体上限分别为 40 / 20 / 20 分钟。单行为条件通常为 30 秒，显式截图为 60 秒；各用例有独立整体上限，以当前测试代码为准。整体预算不是完成时间保证或帧率目标。

山区连续飞行与海岛视觉用例使用 1152×800（1.44 纵横比）；其他默认视口为 1440×1000。这是软件渲染截图负载设置，不改变 High 几何/材质/后处理；不同分辨率的历史图不能直接做逐像素量化比较。

景观切换的相机保持比较使用 1e-8 精度；机型、权威时钟/位姿、控制源与租约仍精确比较。不能为了慢帧或末位浮点差放宽实际行为不变量；预算变更需有 trace 或测量依据。

独立色调截图的取景收敛使用相邻真实帧：平移小于 1 mm、方向矩阵分量变化小于 1e-5，并记录实际值及最终机位。这是截图准备条件，与上述相机保持契约分开；不要求亚微米收敛，也不以参数断言替代像素审查。

曝光、雾与天空颜色统一读取 `scene-appearance.ts`。产品曝光保持 1，飞行曝光为 0.96；默认雾近/远端 2000/7400 m，显式能见度设置仍优先。数值变化只说明实现，是否减少泛白且保留层次须检查新截图。

结构预算来自几何/缓冲计数：

- 地景 Low ≤45,000、Medium ≤100,000、High ≤180,000 三角形。
- 山区两张程序纹理（地表与云），海岛一张云纹理；实例化物体和分级网格有界。
- 每个旋翼曝光显示层 ≤10,000 三角形，双前桨巡航 ≤20,000；不代表整机总面数。
- 航迹最多 384 点、固定缓冲、一个透明 draw call，按局部仿真年龄计算消散。

`renderer.info` 在 High 后处理下可能只是末次 render pass 的 draw calls / triangles；末 pass 的 1 draw / 1 triangle 不是整场景成本。结构预算、Three.js 几何/纹理数量与物理显存/FPS 都是不同指标，不可相互替代。

## 公开 Pages 验收

部署工作流发布 `threejs/dist/` 后执行公开检查，严格限定到 `https://haifengyue.github.io/sky-captain/`。逐文件验证包括规范与旧兼容模型路径，不能用本地预览代替公共子路径；也不能只看到页面 UI 就宣称 WebGL 渲染成功。

公开 smoke 步骤整体上限 8 分钟；旧 query 同页导航保留 60 秒诊断预算并记录导航事件/trace，普通就绪和行为仍为 30 秒。`--assets-only` 只比对资源，不是完整公开三维验收。

部署步骤先于 smoke：smoke 失败时公开页面可能已经更新。检查候选 SHA 的完整工作流终态、资源报告、页面状态、错误列表和截图，才能说明该候选完成了哪些验证。

## 物理与集成边界

景观是程序化虚构布景，白色带是风格化路径提示。低净空、超过 0.6 仿真秒的采样间隔、时间反转、瞬移和生命周期变化会保守断开旧航迹。

新地形不改写外部位姿，也不替换旧 EV50 名义地面/手动命令包络。低空外控可能穿入可见山体；自动避障不是这套视景的能力。

视觉改善、资产哈希不变或渲染 ACK 均不证明连续无碰撞、结构安全、制造可行性、适航性，或 UAVRL/其他外部系统训练成功。有关源资产与独立机械验证，查阅 [PROVENANCE](../models/skytrans/PROVENANCE.md) 和 [REBUILD](../models/skytrans/REBUILD.md)。
