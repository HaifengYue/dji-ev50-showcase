Transwing 飞行展示工作室

本工程只维护一个当前蓝白 P4 参考构型。前端、Blender 源、生成器、Python 接口、示例与必要验证资源应在同一个完整目录中提供，不需要合并多个补充资源包。

当前状态
当前层叠翼、真实移轴与连接机构已通过55阶段独立物理、八项作者验证和前端五阶段：169单元、5飞行、26Python通过，300项联合冻结依赖完整。当前模型图像已通过解码、取景及人工视觉复核，旧模型媒体和旧211输入复用声明不用于本轮。最终身份见项目信息.json及包内PROJECT_MANIFEST.json；真实浏览器与设备GPU未验收。

如何使用
1. 打开 README.md，按说明安装 Node.js 22.12+ 并执行 npm ci、npm run dev。
2. 生产构建使用 npm run build；脚本必须包含 --emptyOutDir false，不清空已有 dist。
3. Python 实时联动需要 Python 3.10+，先运行 python/install.py，再启动 transwing_sim.server，打开服务给出的本机页面并连接 Python 桥。
4. 静态网页可回放 JSON，但不能运行 Python 服务或直接控制本机端口。
5. 完整复验按 docs/VERIFICATION.md；依赖、生成及独立重建命令见 docs/ASSETS.md。复验不得混用旧报告。

保留什么
仅保留当前工程和实际需要的生成、校准、协议、几何与回归测试资源。某些夹具、校准合同或保留表面数据可能留有原始来源标记，用于追溯与复算，并不代表另一个当前飞机模型。不可仅凭名称删除测试依赖。

不随工程交付什么
不纳入迭代备份、旧对比媒体、多套发行包、.git 历史、node_modules、.venv、凭据、环境秘密或用户原始标注截图。当前工程整理不删除或修改原工作目录中的文件。

源码与发布
唯一源码目标是 HaifengYue/dji-ev50-showcase 仓库的 Transwing 分支。本目录与归档不能证明远端已更新；以实际提交、推送和部署确认记录为准。

项目是原创概念可视化，不是原厂 CAD、制造资料、飞控或适航证明。详见 docs/PROJECT.md、docs/DELIVERY.md。
